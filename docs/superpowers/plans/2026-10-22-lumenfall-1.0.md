# Lumenfall 1.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Lumenfall 1.0.0 (`com.sdelavega.lumenfall`): every July code-review item resolved, original Rainfall wallpaper, ÆtherDesk wallpapers vendored from a pinned upstream commit, reproducible locally-signed release, GitHub + F-Droid ready.

**Architecture:** Kotlin Android shell over a Rust core (JNI, cargo-ndk). Work lands on `release/1.0` in `~/src/Lumenfall-1.0`, foundations first (rename, licence, reproducible build), then fixes by module, then wallpapers, then release tooling, docs and device verification.

**Tech Stack:** Kotlin 2.2 / AGP 8.12 / Gradle 9.5 wrapper, minSdk 33, targetSdk 36, arm64-v8a only; Rust edition 2024 (serde, serde_json, thiserror, jni 0.21); JUnit 4 + org.json for JVM tests; `just` for entry points; GitHub Actions for CI.

**Spec:** `docs/superpowers/specs/2026-10-22-lumenfall-1.0-design.md`

## Global Constraints

- Application ID and Kotlin package: `com.sdelavega.lumenfall`. JNI exports: `Java_com_sdelavega_lumenfall_core_LumenfallCore_*`.
- `versionName = "1.0.0"`, `versionCode = 10000` (`major*10000 + minor*100 + patch`).
- The bundle-facing bridge keeps its names: `window.aetherDesk.*`, `livelyPropertyListener`, `onPropertyChange`. Do not rename them.
- New/owned source files carry exactly: `Copyright (C) 2026 Stephen de la Vega` and `SPDX-License-Identifier: GPL-3.0-or-later` in the file's comment syntax. Never "All rights reserved". Vendored wallpapers get no header.
- Never read, print, copy, move or modify `release.jks`, `keystore.properties`, any key, token or certificate private material. Never print the environment (`env`, `printenv`, `set`, `-help` dumps). Never commit `/Users/...` paths.
- No sudo, no system/privacy setting changes, no writes under `/Volumes/*`.
- No push, tag, release, repo creation or visibility change — the coordinator does those only with the user's go-ahead.
- Tests must be JVM unit tests (`app/src/test`) or Rust tests; no instrumented tests. Use only already-declared test deps (JUnit 4.13.2, org.json) unless a task says otherwise.
- arm64-v8a only; minSdk 33. No new runtime dependencies except `androidx.recyclerview:recyclerview:1.4.0` (Task 15).
- Network: wallpapers may never reach `ipapi.co` or `api.bigdatacloud.net` in Lumenfall.
- Commit after each task with a message ending in `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`. Do not stage `.gortex/`, `.claude/`, `.superpowers/`, `dist/`.
- Paths below use `$PKG` = `app/src/main/java/com/sdelavega/lumenfall` and `$TPKG` = `app/src/test/java/com/sdelavega/lumenfall` (after Task 1).
- Per-task verification (until Task 21 adds the full gate): `cargo test --locked` and `./gradlew :app:testDebugUnitTest --console=plain` both pass, plus `./gradlew :app:assembleDebug` when Kotlin/resources changed.

## Review Focus

1. **Odd `LivelyProperties.json`** (unknown type, missing min/max, `items` not an array, min > max, all three file formats) → typed schema degrades to `Text`/`Label`, Settings never crashes. Test: Task 9 `PropertySchemaTest.malformedEntriesDegrade`.
2. **Active bundle deleted or replaced while the wallpaper is visible / Settings open** → engine falls back to the placeholder page, Settings finishes, no crash or zombie WebView. Tests: Task 5 `BundleDeletedBusTest`, Task 10 `BundleStoreTest.deleteActiveClearsAndNotifies`.
3. **Hostile or messy zips** (zip-slip, absolute paths, >2,000 files, undecodable script bytes, missing entry) → clean `Result.Error`, bundle dir removed, never *allowed* on partial screening. Tests: Task 12 `BundleImporterTest`.
4. **Rapid engine churn** (preview + home engine together, rotation, visibility flicker) → listeners unregistered, deep sleep only after real hide, no ticks counted while hidden. Tests: Task 6 `DeepSleepSchedulerTest`, Task 7 `ShimAssetTest.tickSuppressedWhileSuspended`.
5. **Location denied / approximate-only for WeatherAether** → "Set a city" notice, cached location if any, zero requests to ipapi.co / BigDataCloud. Tests: Task 13 `WallpaperNetworkPolicyTest.blocksProprietaryGeoServices`, Task 19 `VendoredWeatherAetherTest.ipFallbackGatedByCapability`.

# Lumenfall 1.0.0

Lumenfall is an Android live wallpaper host for Lively and ÆtherDesk wallpaper
bundles. A thin Kotlin shell runs on Android's native `WallpaperService`; a
Rust core parses, validates and indexes the bundles.

## Highlights

- Runs Lively and ÆtherDesk wallpaper bundles, including their property
  panels and the `window.aetherDesk` / Lively property bridge.
- Eight wallpapers bundled, including the new Rainfall.
- Import your own bundles from a .zip.
- Private by design: bundled wallpapers never reach location lookup services,
  and Lumenfall asks for no accounts and sends no analytics. Weather Aether and
  Neon City (live weather) contact only Open-Meteo
  (`api.open-meteo.com`, `geocoding-api.open-meteo.com`), and their IP-location
  paths stay off because Lumenfall never sets the `ipGeolocation` capability.
- Reproducible builds: two builds of the same source produce a byte-identical
  APK, so you can verify the release against the source.
- Free software, GPL-3.0-or-later.

## Install

- Requires Android 13 (API 33) or newer on an arm64 device.
- Download `Lumenfall-1.0.0.apk`, allow installation from your browser or file
  manager when Android asks, then open Lumenfall, tap a wallpaper, and confirm in Android's preview.
- Verify the download against `Lumenfall-1.0.0.apk.sha256`:
  `shasum -a 256 -c Lumenfall-1.0.0.apk.sha256`.
- Future updates must be signed with the same key. The signing certificate's
  SHA-256 is recorded in `docs/signing-cert.sha256`.
